# Login Page Project

A simple login page built with pure HTML, CSS, and JavaScript. This project demonstrates a password visibility toggle and duplicate submission prevention.

Features
- Inline SVG icons for password toggle (eye open/closed)
- Smooth transitions (0.3s)
- Duplicate submission prevention with loading state
- No external libraries or assets

Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript (ES6+)

Setup
1. Open index.html in a browser or run a static server such as `python -m http.server` from the project root.
2. Open the developer console to see simulated API logs.

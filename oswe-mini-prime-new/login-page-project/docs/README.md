# Login Page Project

A small login page implemented with pure HTML, CSS, and JavaScript.

Features:
- Inline SVG password visibility toggle with animations
- Duplicate submission prevention with disabled/loading state
- No external libraries or dependencies

Tech stack:
- HTML, CSS, JavaScript (ES6+)

Setup:
1. Open `index.html` in your browser (no build steps required).
2. Use the form to test behavior. For a simulated successful login, use an email containing the word `success` (e.g., `success@example.com`).

Notes:
- The project simulates a 2-second API call using `setTimeout`.
- All icons are inline SVGs.

# Login Page Project

This project is a simple login page built using pure HTML, CSS and JavaScript. It demonstrates a small UI component with a user-friendly password visibility toggle and protection against duplicate form submissions.

## Features
- Password visibility toggle (eye icon) inside the input field
- Duplicate submission prevention (button disabled with loading state)
- No external dependencies, fully self-contained

## Tech stack
- HTML5
- CSS3
- JavaScript (ES6+)

## Setup & run
Open `index.html` in a browser to view the login page. For lightweight local testing, a simple HTTP server is recommended:

```bash
# Python 3
python -m http.server 8000
# Node
npx serve
```

Then navigate to `http://localhost:8000` to view the page.

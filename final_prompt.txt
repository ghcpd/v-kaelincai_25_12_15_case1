ISSUES TO FIX
================================================================================

ISSUE #1: Missing Password Visibility Toggle
---------------------------------------------
Current Problem:
- The password input field is a standard <input type="password"> without any 
  show/hide functionality
- Users cannot see what they are typing, which leads to poor user experience
- There is no eye icon button to toggle password visibility

Required Fix:
- Add a toggle button with an eye icon inside the password input field 
  (positioned on the right side)
- Clicking the icon should toggle between showing and hiding the password
- Must use inline SVG icons (no external image files)
- Include smooth transition animations


ISSUE #2: Duplicate Submission Problem
---------------------------------------
Current Problem:
- The login button can be clicked multiple times rapidly
- Each click triggers a new API request (check console logs)
- No visual feedback during submission
- No button state management (disabled/loading state)

Required Fix:
- Implement duplicate submission prevention mechanism
- Disable the button immediately when clicked
- Show loading state with text "Logging in..." and a spinner
- Re-enable button after API response (success or failure)
- Add appropriate cursor styles (not-allowed when disabled)
